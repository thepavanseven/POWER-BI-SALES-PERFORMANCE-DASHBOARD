# Sales Performance Analysis Dashboard

## Project Overview

An interactive Power BI dashboard developed to analyze sales performance and provide meaningful business insights through dynamic visualizations, DAX calculations, data modeling, and time-based analysis.

## Objectives

- Analyze overall sales performance
- Track total sales and quantity sold
- Monitor transaction volume and average price
- Perform time-based sales analysis
- Compare current performance with previous periods
- Provide interactive filtering for business analysis

## Key Features

- Interactive Power BI Dashboard
- Custom Calendar Table
- Data Model and Table Relationships
- DAX Measures and Calculations
- MTD (Month-to-Date) Analysis
- Same Period Last Year Analysis
- Interactive Filters and Slicers
- Sales Performance Visualization
- Product and Customer Analysis

## DAX Measures

The project includes DAX measures such as:

- Total Sales
- Total Quantity
- Transactions
- Average Price
- MTD
- Same Period Last Year

## Dashboard Analysis

The dashboard provides analysis across different dimensions including:

- Brand
- City
- Payment Method
- Mobile Model
- Customer Ratings
- Rating Status
- Time / Date

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modeling
- Power BI Service

## Project Workflow

1. Understanding the dataset
2. Data preparation and transformation
3. Creating a custom calendar
4. Building data model relationships
5. Creating DAX measures
6. Developing interactive visualizations
7. Adding filters and interactions
8. Dashboard development
9. Publishing the dashboard to Power BI Service
